### Bug Fix: Tenancy Page Document Upload
**Status: Complete** ✓

**Issue 1:** "Add new" button was redirecting to grounds page instead of staying on tenancy page

**Fix:** Added `name="action" value="addDocument"` to the Add new button, and check for this in POST handler to redirect back to `/claims/tenancy`.

**Issue 2:** After uploading documents, Continue button and Remove links stopped working

**Root cause:** Nested forms - the Remove button used a `<form>` inside the main form, which is invalid HTML and causes browsers to behave unpredictably.

**Fix:** Changed Remove from nested form to a simple GET link:
```html
<a href="/claims/tenancy/remove-document?documentId={{ doc.id }}" class="govuk-link">Remove</a>
```

Added GET handler for `/claims/tenancy/remove-document` (kept POST handler for backwards compatibility).

## Development Patterns Established

1. **Test-first development:** Read artifacts → Run baseline → Implement → Test → Commit
2. **Error handling:** Return 400 status and render directly (don't redirect) for validation errors
3. **Session storage:** Use `claimService.updateClaim(req.session, 'key', value)`
4. **Navigation:** Previous button uses `href` (link), Continue button uses `type="submit"` (button)
5. **Conditional reveals:** GOV.UK always includes HTML with `govuk-radios__conditional--hidden` class
6. **Avoid nested forms:** Use GET links instead of forms within forms
