# Feature — Analytics Dashboard

## User story

As a prototype owner, I want to view analytics about how users interact with the prototype so that I can identify usability issues, track validation errors, understand navigation patterns, and measure overall engagement.

---

## Context / scope

- Internal tool for prototype owners and UX researchers
- Accessible at `/__prototype-annotator/analytics`
- Google Analytics-inspired dashboard design
- Uses SQLite for data persistence (via sql.js)
- Auto-tracks user activity via Express middleware
- Protected behind access code gate (same as prototype)

---

---

### Automatic tracking

**AC-17 — Track page views**
- Given a user visits any page (excluding static assets, API routes, /__* routes),
- Then a page_view event is logged with session ID and URL.

**AC-18 — Track form submissions**
- Given a user submits a form (POST request),
- When the form is valid (redirect response),
- Then a form_submit event is logged with valid=true.

**AC-19 — Track validation errors**
- Given a user submits a form,
- When validation fails (re-render with errors),
- Then a form_submit event is logged with valid=false and error field names.

**AC-20 — Track navigation actions**
- Given a user clicks Previous or Cancel,
- Then a navigation event is logged with the action type.

**AC-21 — Track continue actions**
- Given a user successfully continues to next page,
- Then a navigation event is logged with action=continue and destination URL.

**AC-22 — Session tracking**
- Given a user accesses the prototype,
- Then a unique analytics session ID is created
- And stored in `req.session.analyticsId`
- And persists across page loads.

## Annotator Dashboard Integration (Optional)

The prototype-annotator dashboard is a pre-built SPA from the npm package. To add an Analytics link to its navigation, inject a script when serving the dashboard HTML:

```javascript
// In app.js - Script to inject analytics link into annotator dashboard navigation
const analyticsLinkScript = `
<script>
  (function() {
    function addAnalyticsLink() {
      const nav = document.querySelector('nav, [class*="sidebar"], [class*="nav"]');
      if (!nav) { setTimeout(addAnalyticsLink, 500); return; }
      if (document.getElementById('analytics-nav-link')) return;
      const links = nav.querySelectorAll('a');
      if (links.length === 0) { setTimeout(addAnalyticsLink, 500); return; }
      const analyticsLink = document.createElement('a');
      analyticsLink.id = 'analytics-nav-link';
      analyticsLink.href = '/__prototype-annotator/analytics';
      analyticsLink.textContent = 'Analytics';
      analyticsLink.className = links[0].className || '';
      const lastLink = links[links.length - 1];
      lastLink.parentNode.insertBefore(analyticsLink, lastLink.nextSibling);
    }
    if (document.readyState === 'loading') {
      document.addEventListener('DOMContentLoaded', () => setTimeout(addAnalyticsLink, 500));
    } else {
      setTimeout(addAnalyticsLink, 500);
    }
    const observer = new MutationObserver(() => addAnalyticsLink());
    observer.observe(document.body, { childList: true, subtree: true });
  })();
</script>
`;

// Serve dashboard with injected script
const serveDashboardWithAnalytics = (req, res) => {
  const indexPath = path.join(dashboardPath, 'index.html');
  fs.readFile(indexPath, 'utf8', (err, html) => {
    if (err) return res.status(500).send('Error loading dashboard');
    const modifiedHtml = html.replace('</body>', analyticsLinkScript + '</body>');
    res.type('html').send(modifiedHtml);
  });
};
```

## Analytics Service API

```javascript
// Initialization
await analyticsService.initialize(customDbPath);

// Tracking functions
analyticsService.trackSession(sessionId, userAgent);
analyticsService.logPageView(sessionId, pageUrl, pageTitle);
analyticsService.logFormSubmit(sessionId, pageUrl, valid, errorFields);
analyticsService.logNavigation(sessionId, pageUrl, action, destination);

// Query functions (all accept days parameter)
analyticsService.getSummaryStats(days);      // Returns {totalSessions, totalPageViews, totalFormSubmits, validSubmits, invalidSubmits, validationRate}
analyticsService.getPageViewCounts(days);    // Returns [{url, views}]
analyticsService.getDropOffAnalysis(days);   // Returns [{url, count, rate}]
analyticsService.getValidationErrors(days);  // Returns [{url, field, count}]
analyticsService.getNavigationPatterns(days);// Returns {continue, previous, cancel}
analyticsService.getDailyActivity(days);     // Returns [{date, sessions, pageViews, formSubmits}]
analyticsService.getRecentEvents(limit);     // Returns [{id, sessionId, eventType, eventName, pageUrl, metadata, createdAt}]
```

## Database schema

```sql
CREATE TABLE events (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT NOT NULL,
  event_type TEXT NOT NULL,    -- 'page_view', 'form_submit', 'navigation'
  event_name TEXT NOT NULL,    -- page title, 'valid'/'invalid', action name
  page_url TEXT,
  metadata TEXT,               -- JSON string with additional data
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE sessions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT UNIQUE NOT NULL,
  user_agent TEXT,
  started_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  last_activity DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## Middleware integration

Add to `app.js` within `initializeAnnotator()`:

```javascript
// Initialize analytics service
await analyticsService.initialize();

// Add analytics routes
app.use('/__prototype-annotator/analytics', (req, res, next) => {
  if (!req.session?.accessGranted) {
    return res.redirect('/access');
  }
  next();
}, analyticsRoutes);

// Add tracking middleware (after session middleware)
app.use(analyticsMiddleware);
```

## Assumptions

1. Uses sql.js (same dependency as prototype-annotator) for SQLite in-memory/file database
2. Database stored at `./data/analytics.sqlite` (dev) or `/home/data/analytics.sqlite` (production)
3. Analytics session ID is separate from Express session ID to persist across session resets
4. Only tracks after user passes access code gate
5. Static assets, health check, and `/__*` routes are excluded from tracking
6. Middleware intercepts `res.render` and `res.redirect` to detect validation success/failure
